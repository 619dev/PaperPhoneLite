# PaperPhoneLite 3.0.0

PaperPhoneLite — лёгкий мессенджер со сквозным шифрованием, личными и групповыми чатами, вложениями, голосовыми сообщениями, надёжной синхронизацией, офлайн-кэшем, push, QR и 2FA.

В версии 3.0.0 удалены Moments, Timeline, все голосовые/видеозвонки, LiveKit и Cloudflare R2. Файлы хранятся только в постоянном томе сервера. Самостоятельное размещение использует Tor v3 onion service без Nginx с прямой передачей на Rust-сервер; MySQL и Redis не публикуются. Web-клиент намеренно не содержит Tor; будущие нативные клиенты должны встраивать Tor и запрещать переход в clearnet. См. [DEPLOY_EN.md](DEPLOY_EN.md).
